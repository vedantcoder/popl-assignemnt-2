Prompt 1: Write my-length in Racket (#lang racket/base) that returns the
number of top-level elements of a list, using only allowed built-ins
(no length, no set!). Use a tail-recursive named let.


Prompt 2: Write my-map in Racket (#lang racket/base) that takes a function f
and a list lst and returns a new list with f applied to each element, in the
same order. No map, no reverse, no append, no set!. Use only allowed built-ins.



Prompt 3: Using my-length and my-map, write (insert-if-short x lst n) in Racket
(#lang racket/base). It inserts x at the front of every list whose length is
less than n, at every level of nesting, including the top-level list and empty
lists. Length is measured on the original list before insertion. Elements that
are not lists stay unchanged. Only allowed built-ins.



Prompt 4: Write (print-insert-result) in Racket (#lang racket/base) that takes
no arguments. It reads x, lst and n from standard input using read, in that
order, calls insert-if-short, and prints the result with display followed by
a newline. It prints no prompt or any other text.



Prompt 5: Write (make-inserter x len-ok?) in Racket (#lang racket/base). It
returns a function of one argument (a list) that inserts x at the front of
every list, at every level of nesting, whose original length satisfies
len-ok?, where len-ok? is a function taking one number. Use my-length and
my-map. Then redefine insert-if-short using make-inserter, so that the file
has a single definition of insert-if-short.
