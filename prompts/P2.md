# Prompts for Problem 2 (P2: Form a Valid Arithmetic Equation)

### Prompt 11
In code/id_q2.pl, start building the arithmetic equation solver. Define an expression tree representation using num(X) for single numbers and op(Op, Left, Right) for operations where Op is one of +, -, *, /. Write eval_expr(Expr, Value) that evaluates an expression tree to an integer Value. Division must be exact (remainder 0) and divisor must not be 0  fail otherwise. Write build_expr(List, Expr) that builds all possible expression trees from a list of numbers, trying all operator combinations and all ways to split the list.

### Prompt 12
In code/id_q2.pl, implement expr_to_string(Expr, String) that converts an expression tree to a canonical SWI-Prolog string. Follow these precedence rules: * and / bind tighter than + and -. Operators are left-associative. Left operand gets parentheses only if its top operator has lower precedence than parent. Right operand gets parentheses if its top operator has same or lower precedence than parent. A single number is never parenthesised. Use number_codes and atom_string for conversion. Verify with these examples: (4+2)*3 should give "(4+2)*3", 8/(4*2) should give "8/(4*2)", 1-(2-3) should give "1-(2-3)", 1+(2+3) should give "1+(2+3)".

### Prompt 13
In code/id_q2.pl, implement generate_equation(List, Equation). It should split List at every valid position j (1 <= j < length), build expression trees for the left and right parts, evaluate both, check they produce the same integer value, convert the equation to canonical string format as "Left=Right", and return the first valid equation found. It must fail (not loop or error) for lists of length 0 or 1, or if no valid equation exists. Use the build_expr and expr_to_string predicates from earlier.

### Prompt 14
In code/id_q2.pl, implement all_equations(List, Equations) that finds all valid equations without duplicates, sorted using sort/2. If none exist, Equations = []. Also implement count_equations(List, N) that gives the length of that list. Test mentally against: all_equations([4,2,5,3], Es) should give 7 equations, all_equations([2,3,4], Es) should give [], all_equations([2,4,8], Es) should give ["2*4=8"].

### Prompt 15
Create tests/test_q2.pl with test cases for P2. Test generate_equation([4,2,5,3], E) succeeds and E is one of the 7 known valid equations. Test generate_equation([2,3,4], E) fails. Test all_equations([4,2,5,3], Es) returns exactly ["4*2-5=3", "4*2=5+3", "4-2=5-3", "4/2=5-3", "4=2*(5-3)", "4=2+(5-3)", "4=2+5-3"]. Test all_equations([2,4,8], Es) returns ["2*4=8"]. Test count_equations([4,2,5,3], 7). Test generate_equation([], E) fails and generate_equation([5], E) fails.

### Prompt 16
Create prompts/P1.md and prompts/P2.md files. P1.md should contain all the prompts I used for Problem 1 , and P2.md should contain all the prompts I used for Problem 2, copied word for word, numbered sequentially.
