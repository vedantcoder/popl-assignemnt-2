# Prompts for Problem 1 (P1: Department Assignment Puzzle)

### Prompt 1
Create the prolog-dev skill file at skills/prolog-dev/SKILL.md for SWI-Prolog 9.x development. Include language version, naming conventions, comment style, how to run and test Prolog files, and a list of known AI failure modes for Prolog.

### Prompt 2
In code/id_q1.pl, write the solution structure for the department assignment puzzle. Define the solution/1 predicate that generates a list of four p(Name, Dept, Lang, Project) terms in order Alex, Ben, Carla, Dana. Use permutation/2 from library(lists) to assign departments, languages, and projects. Use the exact atoms specified: 'Alex', 'Ben', 'Carla', 'Dana' for names; research, development, design, testing for departments; python, java, 'c++', javascript for languages; 'AI', web, embedded, data for projects.

### Prompt 3
In code/id_q1.pl, implement clue/2 predicates for clues 1 to 4. Each clue(N, Solution) should succeed when clue N holds for Solution. 
1. The friend who prefers the AI project does not work in research and is not Dana.
2. Alex does not work in development and does not prefer C++.
3. The friend working in the testing department likes Python.
4. Ben prefers web projects and does not work in testing

### Prompt 4
In code/id_q1.pl, implement clue/2 predicates for clues 5 to 8. 
5. The friend whose favorite language is Java works in the design department.
6. Carla's project preference is not embedded, and her department is not development.
7. Dana's favorite language is not Java, and she works in research or testing.
8. The friend who prefers data projects works in research and does not use JavaScript.

### Prompt 5
In code/id_q1.pl, implement the solve/1 predicate that calls solution/1 and applies all 8 clues using clue/2. Then implement main/0 that calls solve, extracts each person's attributes, and prints exactly four lines in this format:
Alex = [Dept, Lang, Project]
Ben = [Dept, Lang, Project]
Carla = [Dept, Lang, Project]
Dana = [Dept, Lang, Project]
Use format/2 for the output. Do not hardcode the answer!

### Prompt 6
Create tests/test_q1.pl with test cases for the P1 solve functionality. Include a test that runs main/0 and verifies it produces output. Include a test that solve/1 returns a valid solution where all attributes are distinct. Include tests that individually verify each clue/2 predicate holds for the solution. Use the SWI-Prolog testing approach with simple goal-based assertions.

### Prompt 7
In code/id_q1.pl, implement count_solutions/2. count_solutions(Active, N) takes a list of clue numbers Active, finds all solutions that satisfy exactly those clues (ignoring clues not in Active), and unifies N with the count. Use findall/3. Define a helper apply_active_clues/2 that applies only the clues whose numbers are in the Active list.

### Prompt 8
In code/id_q1.pl, first find all solutions satisfying clues 1-8 by running count_solutions([1,2,3,4,5,6,7,8], N) and examining what differs between them. Then add clue(9, Solution) that eliminates all solutions except one, so that count_solutions([1,2,3,4,5,6,7,8,9], 1) succeeds. The clue must NOT mention any friend by name only refer to friends through attribute values. Add a comment directly above it starting with % CLUE 9: followed by the English sentence.

### Prompt 9
Create P1_REPORT.md. State the value of N from count_solutions([1,2,3,4,5,6,7,8], N). Explain what this value tells us about the puzzle — whether the 8 original clues uniquely determine the solution or not, and how clue 9 fixes this. Keep it concise, 4-5 sentences.

### Prompt 10
Update tests/test_q1.pl with additional test cases. Add a test for count_solutions with all 8 clues and verify it returns the expected N. Add a test for count_solutions with all 9 clues and verify N = 1. Add a test with a subset of clues like [1,2,3] and verify N is greater than the full set.
